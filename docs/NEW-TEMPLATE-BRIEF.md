# New template brief

Chỉ cần gửi reference và asset cùng prompt sau:

```text
Đây là mẫu template Canva và đây là các element hỗ trợ bạn làm.

Hãy đọc docs/AI-TEMPLATE-PLAYBOOK.md và triển khai thành một template mới đúng chuẩn Birthday. Mức độ tương đồng cảm nhận mong muốn khoảng 80%.
```

Thông tin bổ sung không bắt buộc:

```text
Concept:
Đối tượng:
Điểm muốn giữ:
Điểm không muốn giữ:
Motion mong muốn:
```

AI phải tự audit file lộn xộn, trình design proposal ngắn và chờ duyệt trước khi sửa code.
