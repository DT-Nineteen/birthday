# Template asset pipeline

1. Define one semantic role per asset.
2. Generate or source each irregular decoration as its own file.
3. Require genuine transparency and generous padding around the complete object.
4. Inspect the image at full size before integration.
5. Reference the complete image with an img element; use object-fit contain when a box is required.
6. Record origin, date, prompt summary and commercial-use status in ASSET-SOURCES.md.
7. Verify every responsive viewport for clipping and unintended overlap.
8. Optimize to WebP or AVIF only after alpha and visual quality pass review.

## Prohibited patterns

- Treating an unstructured moodboard or sticker sheet as a regular sprite atlas.
- Cropping irregular art with fixed square background positions.
- Hiding broken edges beyond the viewport.
- Shipping a generated asset without visual inspection.
- Using third-party assets commercially without documented license.

Use semantic kebab-case names under images/templates/template-id. Version experiments with -v2 or -v3 until approved.
